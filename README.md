#  Projeto Cloud & Docker: Arquitetura Multi-Container

Este projeto simula um ambiente de nuvem corporativa utilizando **Docker** e **Docker Compose**, implementando isolamento de redes e microsserviços.

##  Tecnologias Utilizadas
- **Docker & Docker Compose** (Orquestração e conteinerização)
- **Nginx (Alpine)** (Servidor Web de alta performance)
- **PostgreSQL 15** (Camada de Banco de Dados)﻿
